# Third-party components and licenses

This repository aggregates extension packages produced by the upstream
SpotiFLAC-Extension project and related authors. Their original license files
are preserved inside each `.sflx` package (LICENSE / COPYING / NOTICE entries).

| Package | Upstream source | License |
| --- | --- | --- |
| `ytmusic-spotiflac.sflx` | SpotiFLAC-Extension (zarzet / spotiflacapp) | GPL-3.0 (LICENSE + COPYING inside package) |
| `qobuz-web.sflx` | SpotiFLAC-Extension (zarzet / spotiflacapp) | GPL-3.0 (LICENSE + COPYING inside package) |
| `jiosaavn.sflx` | HemanthJabalpuri/spotiflac-jiosaavn-extension (Mornye-compatible build) | GPL-3.0 (LICENSE + COPYING inside package) |
| `spotify-web.sflx` | zarzet/spotify-web (see package manifest homepage) | per upstream manifest |
| `zen-lossless.sflx` | Written for this repository (ZenMusic) | GPL-3.0 |
| `zen-addon/vendor/crypto-js.js` | crypto-js 4.2.0 (Jeff Mott, art Arthur) | MIT (vendor/LICENSE) |

The registry schema and `.sflx` package layout follow the public
SpotiFLAC extension registry format.

All redistribution here keeps original license texts, copyright notices and
package contents unchanged except for packaging location.
